# 🎫 EasyTicket

> A modern, full-stack online travel ticket booking platform designed to streamline reservations with dedicated portals for clients, transport agencies, and system administrators.

![EasyTicket Banner](./path/to/screenshot.png)

## ✨ Core Features

- **Client Portal:** Search routes, select seats, book tickets securely, and manage booking history.
- **Agency Dashboard:** Manage bus/travel schedules, track available seats, and monitor daily ticket sales.
- **Admin Control Panel:** Oversee platform-wide operations, manage registered agencies, and handle system settings.
- **Automated Notifications:** SMS and WhatsApp notification integration for ticket confirmations and travel reminders.
- **Secure Payments:** Integrated local payment gateways for seamless mobile money and card transactions.

---

## 🛠️ Tech Stack

**Frontend:** Next.js, React, Tailwind CSS  
**Backend:** Node.js, Express, REST APIs  
**Database & ORM:** PostgreSQL, Supabase, Prisma  
**Integrations:** Africa's Talking API, Payment APIs  
**Deployment:** Vercel (Frontend), Railway (Backend/APIs)
